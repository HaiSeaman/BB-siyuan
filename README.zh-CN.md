# 思源笔记 AI 对话面板

给 [思源笔记](https://b3log.org/siyuan/) 用的 AI 助手面板。选一个提示词模板，写下要求，看回答逐字出现，复制回笔记。**也能生图**：选一个画图模型，写一句描述，图片自动存进插件文件夹。

> **只读不写笔记。** 插件从不插入、修改、覆盖你的笔记。回答只显示在面板里，由你自己复制走。生图产生的图片只存在插件自己的数据文件夹里，不会动你的笔记。

## 功能一览

| 功能 | 说明 |
|---|---|
| **提示词模板** | 把常用的系统提示存成模板。点一下即套用，这个对话里的每条消息都按它的规则回答。自带三个示例。 |
| **多套 API、多个模型** | 可以并存多套接口（协议 + 地址 + 密钥 + 模型清单）。顶栏一点即切换。 |
| **生图** | 选一个画图模型就自动进生图模式。支持 1K / 2K / 4K / 4K+ 四档按屏幕分辨率的大小、10 种常用比例，可传参考图做图生图。 |
| **从接口拉取模型** | 调服务商的模型清单接口（`/models`）。聊天模型、画图模型分开列，`embedding`、`whisper`、`tts` 这类不能用的会被滤掉并告诉你跳过了几个。 |
| **流式回答** | 电脑上逐字输出，按 Markdown 渲染。 |
| **复制 / 重发** | 复制自己的话或 AI 的回答。重发是原地替换答案，不会多出一条消息。 |
| **思考强度** | 六档，按厂商自动翻译（GLM、DeepSeek、GPT/o 系列、Claude、Gemini、Kimi、Qwen、MiniMax）。 |
| **MCP 工具** | 支持 HTTP、SSE、本地命令三种连接方式。工具会交给模型，由模型自己决定何时调用。 |
| **历史对话** | 自动保存最近 30 个对话。可以重新打开、接着聊、删单个、一键清空。 |
| **手机端可用** | 安卓 / iOS 思源都能用。请求由思源内核转发，不受跨域限制。 |
| **报错说人话** | 接口和模型报错会翻译成中文，并告诉你下一步该做什么。 |

## 安装

### 用发布页的压缩包

1. 下载 `siyuan-plugin-ai-chat-v1.4.0.zip`。
2. 思源里依次点：**设置 → 集市 → 已下载 → 插件 → 从压缩包安装**，选那个 zip。
3. 启用「AI 对话」，重启思源。

### 手动复制

解压后确认 `plugin.json` 直接位于插件文件夹里：

```
<你的工作空间>/data/plugins/siyuan-plugin-ai-chat/
├── plugin.json
├── index.js
├── index.css
├── icon.png
└── net-proxy.cjs
```

> `plugin.json` **必须**在这一层的根部，不能再套一层文件夹，否则思源找不到清单。

### 环境要求

- 思源 **3.8.5** 或更新。
- 电脑：Windows / macOS / Linux。
- 手机：安卓 / iOS / 鸿蒙。

## 快速开始

1. 打开面板：点右侧栏底部的 **AI 生成** 图标，或用顶栏插件菜单，或按 `Alt+Ctrl+A`（Mac 是 `⌥⌘A`）。
2. 点 **⚙ 设置 → API 与模型**。
3. 填一张 API 卡片：
   - **协议**：绝大多数中转站选 `OpenAI 兼容`。
   - **接口地址**：例如 `http://127.0.0.1:8080/v1`。
   - **API Key**：你的密钥。
   - **模型**：手打一个名字，或点 **从接口拉取**。
4. 点 **测试这个 API**，能看到模型回话就算通了。
5. 回到面板，写下要求，按 `Ctrl+Enter`（或点 **发送**）。

## 多套 API 与多个模型

每张 **API 卡片** 放一套协议、地址、密钥，以及它自己的模型清单。温度、思考档位、历史条数是全局共用的。

- **+ 添加 API**：再加一张卡片。
- **设为当前**：把这张卡切成正在用的那套。
- **点模型名**：立刻切到这个模型。顶栏会跟着变，并提示「已切到 X」。
- **×**：删掉单个模型。
- **清除其他模型**：保留当前选中的那个，其余一次清掉 —— 拉回来几十个模型时很好用。

### 拉取模型清单

点 **从接口拉取**。插件会调服务商的模型清单接口，把结果合并进现有清单。

有两条规矩值得知道：

1. **不会自动帮你选。** 拉取只往清单里加名字。中转站的清单头一项常是 `text-embedding-3-small`，自动选上会让下一次请求必然失败。
2. **明显不能聊天的会被滤掉** —— `embedding`、`bge`、`whisper`、`tts`、`rerank`、`moderation`。画图模型不会滤掉，而是单独标成「画图」留下来。只是「看起来可疑」的名字不会被删，只在界面上显示成灰底。
3. **支持勾选与手动标画图**：每个模型前可勾选常用项，顶栏只列勾过的（老配置默认全勾）；「清除其他模型」保留已勾选、画图模型和当前模型。认不出的画图模型可点「标为画图」手动指定。

如果你的服务商不开放模型清单接口，直接手打模型名就行。

### 画图模型

拉回来的清单里，画图模型会一起进来（以前是被当垃圾滤掉的）。它们在设置页显示成橙色底，带一个「画图」小标签。

点它 = 切到生图模式。详见下一节。

## 生图

### 怎么用

1. 点顶栏的模型名，在清单里点一个带「画图」标签的模型（比如 `gpt-image-1`、`dall-e-3`、`flux-schnell`）。
2. 面板自动进入生图模式：提示词条和 MCP 条会收起，输入框的按钮变成 **生成**。
3. 在输入框里用中文描述你想要的画面。
4. （可选）点 **上传** 选一张本地图当参考图；点 **大小** / **尺寸** 调整出图规格；点 **优化** 让聊天模型帮你把话润色成中文提示词。
5. 点 **生成**。

生成完的图片会出现在对话里，底下有 **复制图片** 和 **保存到电脑** 两个按钮。

### 输入框上方的按钮

| 按钮 | 说明 |
|---|---|
| **图片** | 直接在系统资源管理器中打开自动保存图片的文件夹（手机端显示完整路径）。 |
| **上传** | 选一张本地图（PNG / JPG / WEBP，8 MB 以内）当参考图。有参考图时走图生图接口。选完会在输入框上方显示文件名，点 × 去掉。 |
| **大小** | 1K / 2K / 4K / 4K+ 四档按屏幕分辨率：长边分别为 **1920 / 2560 / 3840 / 4096**（如 1K + 16:9 = 1920×1080）。短边按比例自动算，并凑成 8 的倍数。 |
| **尺寸** | 10 种比例：1:1、4:3、3:4、16:9、9:16、3:2、2:3、5:4、4:5、21:9。 |
| **优化** | 用**聊天模型**把你输入框里的话改写成一段中文提示词，直接替换输入框内容。不满意可以再点一次。 |

控制条上一直显示这次会出多大的图，比如 `2560 × 1440`。

### 「优化」用哪个模型

生图模型不会写字，所以优化一定用**聊天模型**。插件记着"你上次选中的聊天模型"：

- 就算顶栏现在停在画图模型上，点「优化」照样用那个聊天模型
- 那个模型被删掉了，就退到第一个能聊天的
- 一个聊天模型都没有时，会直接告诉你「去设置里加一个」，不会拿画图模型去发一次注定失败的请求

### 图片存在哪

```
<工作空间>\data\storage\petal\siyuan-plugin-ai-chat\images\img-<时间戳>-<尺寸>.png
```

- 图片**不会**进 `sessions.json`。存档里只记路径、尺寸和提示词 —— 一张 4K 图的 base64 有十几兆，塞进存档会让历史越用越慢。
- 关掉面板再开、重新打开历史对话，图片都还在。
- 删单个历史 / 清空全部历史时，对应的图片文件会一起删掉。
- 存文件失败时图片仍然显示在对话里，你可以用「保存到电脑」自己存一份。

### 4K 不是每个模型都给

| 模型 | 实际接受的尺寸 |
|---|---|
| `gpt-image-1` | 1024×1024、1536×1024、1024×1536 |
| `dall-e-3` | 1024×1024、1792×1024、1024×1792 |
| 其它（Flux / SD / 中转站自建） | 一般按你选的原样发 |

碰上这两种官方模型，插件会自动换成**比例最接近**的那个，并在控制条上写明「实际 1024 × 1024（已换）」。

### 生图模式的边界

- **只支持 OpenAI 兼容协议。** Claude 原生和 Gemini 原生没有这套图片接口，选了会提示你去改协议。
- **需要服务商支持。** 不是所有中转站都开了 `/images/generations`。报 404 通常是这个原因。
- **一次出一张。** 界面上固定 `n=1`，多出几张的接口没做。

## 提示词模板

模板正文会成为 **系统提示**，也就是告诉模型「你是谁、按什么规则写」。

| 变量 | 含义 |
|---|---|
| `{{date}}` | 今天的日期，如 `2026-11-20` |
| `{{time}}` | 当前时间，如 `21:30` |
| `{{weekday}}` | 星期几 |
| `{{doc_title}}` | 当前打开文档的标题 |

几点要注意：

- **点模板是套用，不是发送。** 点一下只绑定规则，内容还是要你自己写、自己发。
- **套用后一直生效。** 这个对话里的每条消息（包括追问）都会带上它，直到你点 **退出**。
- **单花括号不是变量。** `{这样写}` 会原样发给模型。要用变量必须写双花括号。
- **自带三个示例**，可以改也可以删。就算全删了也会自动恢复默认，不会出现空列表。

### 右键菜单

在笔记里任意位置右键，能看到 **AI 生成（打开面板）**，以及每个模板一条。点某个模板只是套用规则并打开面板，**不会直接发送**。

## 复制与重发

两个按钮都在**你自己发的**消息下面。

| 按钮 | 行为 |
|---|---|
| **复制** | 复制这条消息的文字。手机上优先走安卓原生桥，其次 `navigator.clipboard`，最后 `execCommand`。 |
| **重发** | 用同样的文字重新问一遍，**原地替换原来那条回答**。 |

重发**不会新增**一组消息。这个问题的「我的话 + 回答」在记录里始终只有一组。发给模型的历史只截到这条消息**之前**，所以模型不会看着自己上一次的答案再答一遍。

重发用的是**当前**绑定着的模板，不是当初那条消息用的模板 —— 你改了规则想让答案按新规则重做时，这样才顺手。

回答正在生成时，两个按钮都不让点。

## 思考强度

六档：**关 / 最小 / 低 / 中 / 高 / 最高**。插件会翻译成当前模型认识的写法。

| 模型系列 | 实际发送 |
|---|---|
| GLM | `low` / `high` / `max`（没有中档，也关不掉） |
| DeepSeek | `high` / `max`（v4 在低档位也会发 `high`） |
| GPT / o 系列 | `minimal` / `low` / `medium` / `high` |
| Claude 原生 | `thinking.budget_tokens` + `effort` |
| Claude 走 OpenAI 兼容 | `low` / `medium` / `high` |
| Gemini | `thinkingLevel`：`LOW` / `MEDIUM` / `HIGH` |
| Kimi / Qwen / MiniMax | `minimal` / `low` / `medium` / `high` |

模型名认不出来时，干脆不发思考参数 —— 宁可少一个功能，也别被严格的网关直接 400。

> **实测结论：** 作者用的中转站上，`glm-5.3` 无法真正关闭思考。只有 `reasoning_effort=low` 能压到不输出思考内容。即便如此模型偶尔还是会自己输出，那是模型自身行为。不想看就关掉 **显示思考过程**。

## MCP 工具

插件**不自带**任何 MCP 服务器，需要你自己添加。

### 添加服务器

1. 面板上点 **MCP**。
2. 点 **+ 添加 HTTP** 或 **+ 添加本地命令**。
3. 填名字（模型靠它区分工具）和地址或命令。
4. 保存，点 **测试所有服务器**。

| 类型 | 填什么 | 哪里能用 |
|---|---|---|
| HTTP | 网址，如 `http://127.0.0.1:3000/mcp` | 全都行 |
| SSE（旧版） | 网址 | 全都行 |
| 本地命令 | 命令 + 参数，如 `npx` `-y @modelcontextprotocol/server-time` | 仅电脑 |

想马上试一个，可以用官方测试服务器：

```text
npx -y @modelcontextprotocol/server-everything
```

### 模型怎么用工具

连上的工具会写进请求的 `tools` 字段。模型觉得需要调用时，面板会显示 **「正在调用工具：服务器 / 工具名」**，插件把结果回灌给模型，模型接着回答。有轮数上限（默认 8 轮），防止死循环。

### 安全边界

- 本地命令**不开 shell**，参数单独传，注入的 `&` 或 `|` 不会被执行。
- 名字里带 `delete`、`write`、`update`、`remove`、`insert`、`create` 的工具会被识别为写操作，但**仍然会执行**。只连你信得过的服务器。
- 每个服务器独立连接，一个坏了不影响其他的。
- 工具名会先清洗成 ASCII 再发给模型，执行前再按映射表还原成原始名字。

## 历史对话

每次回答结束后自动保存。

- 最多 **30** 个对话，最近的排最前。
- 点一条就切过去，可以接着聊。
- **×** 删单个；**清空全部历史** 在二次确认后一次删光。
- 清空时会连当前屏幕上这段对话一起清 —— 否则下一次回答结束又会把它存回去。
- 内容没变化不会重复存，所以列表顺序不会乱跳。
- 模板**不会**跟对话一起存。切回旧对话后要重新套用。

## 协议与服务商

| 协议 | 对话地址 | 鉴权头 |
|---|---|---|
| OpenAI 兼容 | `{base}/chat/completions` | `Authorization: Bearer` |
| Claude 原生 | `{base}/v1/messages` | `x-api-key` + `anthropic-version` |
| Gemini 原生 | `{base}/v1beta/models/{model}:streamGenerateContent?alt=sse` | `x-goog-api-key` |

模型清单地址分别是：`{base}/models`、`{base}/v1/models`、`{base}/v1beta/models`。

任何 OpenAI 兼容网关都能用第一种协议：各类中转站、Ollama、vLLM、LM Studio、one-api 等等。

## 配置说明

### 每张 API 卡片

| 字段 | 说明 |
|---|---|
| 名称 | 显示用的标签，如「中转站A」 |
| 协议 | `openai` / `anthropic` / `gemini` |
| 接口地址 | 接口根地址 |
| API Key | 明文保存在插件数据目录 |
| 模型清单 | 这套接口下有哪些模型名 |
| 当前模型 | 现在选中哪个 |

### 全局偏好

| 字段 | 默认值 | 说明 |
|---|---|---|
| 温度 | `0.7` | 采样温度 |
| 最大输出 tokens | `4096` | 回答长度上限 |
| 思考强度 | `高` | 思考档位 |
| 显示思考过程 | 关 | 是否显示模型的思考内容 |
| 带几条历史 | `10` | 每次带上多少条过往消息 |
| 上下文上限 | `200000` | token 预算；填 `0` 不检查 |
| 工具轮数上限 | `8` | 一轮里最多调用几次工具 |

### 数据存在哪

| 文件 | 内容 |
|---|---|
| `settings.json` | API 配置、当前 API、全局偏好 |
| `templates.json` | 提示词模板 |
| `mcp.json` | MCP 服务器定义 |
| `sessions.json` | 历史对话 |

全部位于 `<工作空间>/data/storage/petal/siyuan-plugin-ai-chat/`。**密钥是明文存储的**，别把带密钥的截图公开出去。

## 出错了怎么办

| 看到的话 | 意思 |
|---|---|
| 密钥不对或已失效 | 检查 API Key |
| 接口地址找不到 | 看看地址末尾该不该带 `/v1` |
| 请求被拒绝（400） | 多半是模型名写错了 |
| 服务商那边出错了（500/502） | 对方的问题，等几分钟再试 |
| 内容太长了 | 点「新对话」重来，或把内容写短一点 |
| 本地 MCP 程序没能启动 | 检查命令和参数 |
| 模型不存在 | 这个名字不在服务商清单里，重新拉一次清单 |

认不出来的错误会保留原文，方便你自己去搜。

## 开发

```powershell
npm install
npm test                 # 1496 项断言，50 个文件
npm run build            # 构建到 dist/
npm run pack             # 构建 + 生成可安装的 zip
npm run install-plugin   # 构建 + 直接复制进思源工作空间
```

另外两个常用命令：

```powershell
npx svelte-check --tsconfig ./tsconfig.json   # 类型与模板检查
node scripts/oneclick-pack.mjs                # 一步完成构建 + 打包
```

## 隐私与安全

- **没有遥测。** 除了你自己配置的接口地址，任何地方都不会收到数据。
- **密钥只在本机**，存在插件数据目录里，明文。
- **不会自动写入笔记。** 插件从不调用思源的写块接口，文字由你自己复制。
- **本地 MCP 不经过 shell。** 任何地方都没有 `shell: true`，Windows 上的参数也做了转义。

---

## 已知限制

- **界面交互没有自动化测试覆盖。** 点击是无界面验证的（真实挂载组件 + 派发事件），但实际主题下的观感得用眼睛看。
- **手机端没有流式输出。** 内核转发会等模型全部写完才返回，这是思源内核的限制，不是插件偷懒。
- **上下文长度是估算的**，大约两字符算一个 token。它是预警，不是精确计数。
- **暂不支持模板导入导出。**
- **MCP 服务器暂不支持 OAuth**，只能填静态请求头。
- **没有对话搜索**，只列最近 30 个。
- **非聊天模型的过滤名单刻意写得很窄。** 漏掉的名字只是出现在清单里、用了会报错；误杀则会让本来能用的模型消失。
