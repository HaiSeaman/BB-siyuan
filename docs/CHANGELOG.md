### 修复：超长提示里的过时文案

`tokens.ts` 的提示原本写「减少选中的内容后再试」，但「选中内容 / 素材」功能在 v1.1.0 就已经删掉了，会让人找不到对应按钮。现在改成「点「新对话」清空历史，或把这次的内容写短一点再试」。

### 整理：`.gitignore` 补齐并加注释

根目录与插件目录两份都重写了，每节都有中文注释说明为什么忽略：

- 根：`node_modules/`、`dist/`、`dev/`、`.test/`、`pack-log.txt`、编辑器与系统文件、`.qwen/tmp/`、思源数据目录
- 插件：依赖、构建产物、`pack-log.txt`、编辑器文件、`*.bak`/`*.orig`/`*.rej`/`*.tmp` 备份
- 安装包 `siyuan-plugin-ai-chat-v*.zip` **故意保留入库**，方便发布时直接取用

### 新增：我发出的消息多了两个按钮

- **复制**：点一下就复制自己发的那句话，不用手划选
- **重发**：点一下用这条原话重新生成，回答**直接替换原来那一条**

重发不新增消息 —— 要的是「同一条消息换个答案」，点完聊天记录里还是一组「原话 + 回答」，不会变成两组。发给模型的历史也只截到这条之前，否则等于让它看着自己的旧答案再答一遍。
重发用的是**当前**绑定的提示词规则，不是当初那条消息用的规则 —— 想按现在的规则再生成一次时，这样才顺。生成中两个按钮都不让点，会提示「等这一轮结束」。

### 修复：从接口拉来的模型，选中后用不了

三个原因，一起修了：

1. **点模型名不会真的切过去**：在别的 API 卡片里点模型名，只改了「这套 API 记住哪个模型」，没改「当前用哪套 API」。所以顶栏还显示旧模型，发出去还是旧模型 —— 看起来就是点了没反应。现在点一下就连 API 带模型一起切，顶栏立刻跟着变，并提示「已切到 X」。
2. **拉取后偷偷选中清单第一个**：中转站的模型清单头一个常是 `text-embedding-3-small`、`whisper-1` 这类不能聊天的，自动选中就必然报错。现在拉取只往清单里加，不自动选；一个模型都没有时才补一个能聊天的。
3. **清单里混着不能聊天的模型**：`embedding`、`whisper`、`tts`、`rerank`、`dall-e`、`flux` 这些会被滤掉，并告诉你跳过了几个。名单写得很窄，宁可漏也不误杀；长得像不能聊天的在界面上显示成灰底虚线，点之前就能看出来。

另外：删掉当前模型时，会退回**下一个能聊天**的，而不是清单第一个。

### 新增：一键「清除其他模型」

模型清单右上角多一个按钮，二次确认后清掉**没有选中**的模型，只留当前选中的那个。

以前的做法是把当前选中的也一起清掉，等于刚挑好又白挑一次。现在的确认框会写清楚「清除另外 N 个，只留当前选中的「X」」。
另外两个小保护：还没选中模型时会提示先点一个；只剩一个模型时直接说「没有可清除的」。

### 新增：历史对话一键清空

历史抽屉里多了「清空全部历史（N 个）」，二次确认后全部删掉，不用一个个点 ×。
当前正在聊的内容也会一起清空，否则下一轮生成会把它重新存成一条历史，看起来像没删干净。

### 修复：设置改完又自己变回去

保存是延迟 400ms 写盘的，以前会把按下那一刻的旧配置排进队列，期间你再改别的字段，旧配置就把新改动整份盖掉。现在写盘前现取最新状态，所有改动走同一条保存路。

## v1.2.0

**主题：多 API 多模型 + 手机端可用**

### 新增：多套 API、多个模型

以前只有一份配置（一个协议、一个地址、一个 Key、一个模型名）。换服务商就得手改地址、改 Key、改模型名，改错一次还得重填。

现在：

- 可以并存多套 API，每套有自己的协议、地址、Key、模型清单
- 顶栏那个「中转站A · glm-5.3 ▾」变成**真的切换入口**，点开按 API 分组列出所有模型，点一下就切
- 设置页「API 与模型」改成卡片式：每张卡一套 API，能展开编辑、收起只看摘要
- 模型名可以手打，也可以点「从接口拉取」自动获取
- 每张卡有独立的「测试这个 API」，结果只显示在它自己下面

**一键拉取适配了三家：**

| 协议 | 请求地址 | 返回结构 |
|---|---|---|
| OpenAI 兼容 | `{base}/models` | `data[].id` |
| Claude 原生 | `{v1}/models` | `data[].id` |
| Gemini 原生 | `{v1beta}/models` | `models[].name`（去掉 `models/` 前缀，只留能聊天的） |

> 有的中转站不开放这个接口，那就手填。拉取失败会明确说原因，不会静默失败。

### 新增：手机端（安卓 / iOS）

以前手机上**完全用不了**，三层原因叠加：

1. `plugin.json` 没声明 `mobile`，内核判定不兼容，连插件启动代码都不执行
2. 手机没有 `window.require`，桌面那条主进程网络通道根本不存在
3. 手机没有右键菜单、没有停靠栏，也没有任何能打开面板的入口

现在三条都解决了：

- 清单声明 `mobile` + `android`/`ios`/`harmony`
- 请求改走思源内核自带的 `/api/network/forwardProxy`，由内核代为发出，天然无跨域
- 顶栏插件菜单加了「AI 生成」入口；`openDock` 补了手机分支（按侧栏 tab 找并滑出）

**手机端与电脑的差异（都是思源的限制）：**

| 项目 | 电脑 | 手机 |
|---|---|---|
| 发请求 | 插件主进程代理 | 思源内核转发 |
| 显示 | 逐字流式 | 全部写完一次性显示 |
| 发送 | `Ctrl+Enter` | 点「发送」（小键盘也有发送键） |

手机端另外适配：复制按钮走安卓原生剪贴板、切换器从底部弹出、按钮加大、本地命令类 MCP 提示「仅桌面版可用」。

### 新增：开发者文档

- `docs/ARCHITECTURE.md` —— 数据结构、三条网络通道、界面层级、MCP、红线
