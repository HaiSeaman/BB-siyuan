## 二、中文发布说明（直接复制）

```markdown
## v1.4.0

这个版本最大的变化是**能生图了**。同时把生图这一路上能踩的坑基本都填平了，
并修了一批聊天侧的老问题。

### 一、生图：选画图模型就画图

顶栏模型名点开，清单里画图模型带一个橙色「画图」标签。点它，面板自动进入**生图模式**：

- 提示词条和 MCP 条自动收起（图片模型不吃系统提示，也不会调工具）
- 「发送」变成「生成」，顶栏小圆点从绿变橙
- 控制条最末有「💬 对话」，点一下切回上次用的聊天模型

用的是 OpenAI 标准接口：文生图 `/images/generations`，图生图 `/images/edits`。

### 二、输入框上方四个按钮

**图片 / 上传 / 大小 / 尺寸 / 优化**

- **图片**：直接打开保存图片的文件夹
- **上传**：选一张本地图当参考图（PNG/JPG/WEBP，8MB 以内），做图生图
- **大小**：1K / 2K / 4K / 4K+，菜单里直接显示长边像素
- **尺寸**：10 种常用比例（1:1、4:3、3:4、16:9、9:16、3:2、2:3、5:4、4:5、21:9）
- **优化**：用**聊天模型**把你输入框里的话改写成一段中文提示词

### 三、图片自动存进插件文件夹

```
<工作空间>\data\storage\petal\siyuan-plugin-ai-chat\images\
```

- 图片**不塞进存档**。存档里只记路径、尺寸和提示词，否则一张 4K 图的 base64 就有十几兆
- 关掉面板再开、重开历史对话，图片都还在
- 删历史 / 清空历史时，对应的图片文件一起删掉

每张图底下有两个按钮：**复制图片**（真把图片放进剪贴板）和**保存到电脑**（弹原生另存为）。

### 四、尺寸改成按屏幕分辨率

以前 1K 是「长边 1024」，选 1K + 16:9 只出 1024×576，铺不满屏幕。现在：

| 档位 | 16:9 | 1:1 | 9:16 | 铺满什么屏 |
|---|---|---|---|---|
| 1K | 1920×1080 | 1920×1920 | 1080×1920 | 1080p / 普通笔记本 |
| 2K | 2560×1440 | 2560×2560 | 1440×2560 | 2K 显示器 |
| 4K | 3840×2160 | 3840×3840 | 2160×3840 | 4K 显示器 / 电视 |
| 4K+ | 4096×2304 | 4096×4096 | 2304×4096 | 电影 DCI 4K |

### 五、一个 API 里能多选模型

模型名前加了勾选框：勾几个，顶栏就只显示几个；没勾的名字在设置页变淡；
正在用的那个不能取消勾选。老配置升级上来默认全勾，行为不变。

点「清除其他模型」时，**勾选的、画图模型、当前在用的全部保留**，只清没勾也没在用的。
（以前只保留当前那一个，勾了 5 个会只剩 1 个。）

### 六、修掉的主要问题

- **`gemini-3.1-flash-image` 这类模型认不出来**：表现为「配了画图模型却说没有」、4 个按钮全不显示。现在名字里带 `image` 就算画图模型；认不出来的还能在设置页手动「标为画图」。
- **4 个按钮以前一个都看不到**：它们只在生图模式渲染，而模式又依赖模型识别。现在常驻，位置在思考档位右边。
- **图片「能复制能保存，但看不见」**：服务商给的 JPEG 被命名成 `.png`，思源拒绝渲染；同时模板调用函数导致数据更新后不重渲染。现在按文件头字节判断真实类型，模板改成查响应式映射表。
- **正文里的图片只当文字**：Gemini 系把图塞在文字里返回，以前只是一个通用「复制」，还让存档涨到 1MB。现在自动抽成图片卡片，大图搬进 `images/`。
- **「图片」按钮打不开文件夹**：路径里多拼了一层 `data\`。现在兼容两种情况，并加了四层打开兜底。
- **生图的并发与超时问题**：停止后立刻再生成会并发两轮；「停止」是假停（底层还在跑 5 分钟）；桌面通道忽略超时参数；流式通道没有超时会把界面永远卡在「正在生成」。
- **正文插图文件名冲突**：同一秒的多张图会同名互相覆盖，直接丢图。
- **停止后留一个空白气泡**：界面和存档不一致。
- **优化提示词漏传手动标记名单**：手动标成画图的模型会被选去优化，必然失败。

### 七、文档与测试

- README、架构说明、测试指南、变更记录、发布说明 **全部中英双语**
- **49 个测试文件 / 1459 项断言**（上一版 33 / 841）

### 升级注意

- 直接覆盖安装即可，配置和历史都会保留。
- 如果你之前在别的版本里生过图，那些图片会在打开会话时自动按真实类型改名，引用同步更新。
- **生图只支持 OpenAI 兼容协议**，且需要服务商开放 `/images/generations`。
- 接口地址**记得带 `/v1`**，少了会 404 `Invalid URL`。
```

1. 下载自己刚上传的 zip，解压确认 `plugin.json` 在根部、`version` 是 `1.4.0`。

   - 面板能打开
   - 设置里能看到「勾选框」
   - 选一个画图模型能进生图模式，4 个按钮都在
   - 点「图片」能打开文件夹
